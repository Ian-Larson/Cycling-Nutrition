<objective>
Eliminate two coupled Garage layout bugs in a single surgical edit to `src/pages/gear.tsx`:

- **GEAR-01:** The "Due Soon" service preview band currently renders when `tab !== 'due'` — backwards from the requirement that it appear only on Service.
- **GEAR-02:** The band renders as a sibling above `<Tabs>`, so the tab strip's vertical position depends on whether the band is mounted. Switching tabs causes a vertical jump.

Both bugs collapse to one fix: move `<GearDuePreviewBand>` from its sibling-above-Tabs position into the existing `<TabPanel value="due">` block, rendering it above the existing `<GearDueList>`. After the move, the tab strip is the first child of the right-section in every state (no jump), and the band is mounted only when the Service panel is active (correct visibility).

Purpose: The Garage feels stable — no vertical jump between sub-tabs — and "Due Soon" only appears where it makes sense (Service tab).

Output: An updated `src/pages/gear.tsx` with the GearDuePreviewBand moved inside `<TabPanel value="due">`. Lint and build green. Zero behavior change to Active or History tabs.
</objective>
