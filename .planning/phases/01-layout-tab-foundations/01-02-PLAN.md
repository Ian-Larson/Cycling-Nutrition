export function TabPanel({ value, children, className, keepMounted }: {

  children: ReactNode;
  className?: string;

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User keyboard input → tablist | Arrow / Home / End keys drive focus and selection. Canonical `Tabs` uses `event.preventDefault()` only on the recognized keys; other keys propagate normally. |
| Screen-reader API → DOM ARIA | `role="tab"`, `aria-selected`, `aria-controls`, `aria-labelledby`, `tabindex` are the contract. Replacing the hand-rolled implementation with the canonical one preserves the same ARIA shape. |
| React component context | `<TabPanel>` reads `<Tabs>` context via `useTabsContext`. Misplacement (panel outside provider) throws — caught at runtime in dev. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering (a11y regression) | Tablist ARIA semantics | mitigate | Canonical `Tabs` (`src/components/ui/tabs.tsx`) implements the full ARIA tablist contract (verified by inspection: roles, `aria-selected`, `aria-controls`, `aria-labelledby`, `tabIndex` roving, `hidden` on inactive panels). Acceptance criteria grep `<TabList ` and `label="Gear view"` to confirm a labeled tablist. The hand-rolled `GearTabs` had `aria-label="Gear view"` — preserved verbatim via `label="Gear view"` prop. |
| T-02-02 | Tampering (focus management) | Keyboard navigation | mitigate | Canonical `Tabs` implements ArrowRight/ArrowDown → next, ArrowLeft/ArrowUp → previous, Home → first, End → last with focus + selection both moving. The hand-rolled `GearTabs` had identical key bindings. Roving tabindex (`tabIndex={selected ? 0 : -1}`) is preserved by the canonical `<Tab>`. |
| T-02-03 | Denial of service (visual layout shift) | Garage tab strip x-position | mitigate | Wave 1 (Plan 01) already removed redundant `max-w-6xl` from the page wrapper, so `.page-shell` is the sole width source. This plan does not change the row layout (`flex flex-col gap-2 ... sm:flex-row sm:items-center sm:justify-between`). The canonical Tab pill has `min-h-11 md:min-h-10` matching the touch-target floor. Verified by grep on the row's outer div className remaining intact. |
| T-02-04 | Information disclosure | n/a | accept | Pure UI-primitive swap; no data flow, auth, or API call touched. Garage data still flows through the existing `useStore` selectors and the unchanged child components (`ActiveSetupList`, `GearDueList`, `GearHistoryTable`). |
| T-02-05 | Repudiation | n/a | accept | Standard git history; the diff is large but the change set is mechanical (replace hand-rolled implementation with canonical equivalent). |
| T-02-06 | Spoofing | n/a | accept | No identity, auth, or session surface touched. |
| T-02-07 | Elevation of privilege | n/a | accept | No permission boundary, no role check, no Supabase RLS policy touched. |
| T-02-08 | Tampering (state desync) | Tab state (`useState<GearTabValue>`) | mitigate | The local `GearTabValue` type is preserved (defined inline rather than imported). The cast `(v) => handleTabChange(v as GearTabValue)` is safe because the only `<Tab value="">` strings are exactly `'active'`, `'due'`, `'history'`. Acceptance criteria grep all three `<Tab value="..."` strings to catch typos. |

No `high` severity threats — this is a structural primitive swap. The medium-severity threats (a11y, focus) are mitigated by reusing a primitive that already implements the full contract that `gear-tabs.tsx` was approximating.
