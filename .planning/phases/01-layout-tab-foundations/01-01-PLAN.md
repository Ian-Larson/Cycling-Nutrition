<objective>
Strip the redundant `max-w-6xl` className from the 8 page wrappers listed in UI-SPEC §Foundation 1. Every page already applies `.page-shell`, which itself declares `mx-auto max-w-6xl px-4` (mobile) and `padding-inline: 1.5rem` (desktop md+). The duplicated `max-w-6xl` is dead duplication that creates drift risk: any future single-page edit (e.g. someone changes one page to `max-w-5xl`) silently breaks the no-shift contract.

Purpose: Establish a single source of truth for shell width and side padding so that downstream phases (2/3/4) cannot accidentally diverge per-surface. This is LAYOUT-01.

Output: 8 page files each with `max-w-6xl` removed from the top-level wrapper className. No other changes. `.page-shell` utility in `src/index.css` is unchanged — it already holds the canonical values.
</objective>
