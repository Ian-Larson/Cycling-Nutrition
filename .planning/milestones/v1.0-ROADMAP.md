## Overview

A polish-only sweep across the shipped Domestique surfaces — Fuel Plan, Garage, and Account — plus a documentation realignment. The goal was consistency: same controls in the same places with the same spacing, so a rider can produce a precise fueling plan and confirm kit readiness in seconds. Foundations first (page-shell padding + a single canonical tab switcher) so per-surface work became mechanical reuse, then each surface in parallel, then docs realigned to shipped reality. No new features, no backend changes, no new UI primitives — reused what was already in `src/components/ui/`.

## Milestone Summary

**Decimal Phases:** None — execution stayed on the planned 1–5 path with no urgent insertions.

**Key Decisions:**
- Keep orange `#f8622e` brand — user confirmed; avoided large-scale token churn during a polish-only milestone.
- Defer dark mode — out of scope; reduced design surface area.
- Foundations-first phasing — layout shell + canonical tab component changes propagated to every per-surface phase, making the per-surface work mechanical.
- Update PRODUCT.md to reality (not the other way around) — shipped product is the source of truth; aspirational palette/dark-mode language was creating drift.
- `/impeccable` as the per-phase planning lens — matches the design-quality nature of the work.

**Issues Resolved:**
- Page-shell horizontal layout shift between primary tabs (LAYOUT-01).
- Two competing tab implementations (`gear-tabs.tsx` vs canonical `<Tabs>`) → consolidated to one (LAYOUT-02).
- Right-rail nesting / duplicate "bottles" inventory entry (FUEL-01, FUEL-03).
- Setup-flow label ambiguity ("Bottles" / "Fuel" → "Available bottles" / "Fuel selections") (FUEL-01, FUEL-02).
- Singular/plural copy bugs in quick counter (FUEL-04).
- "Due Soon" card pushing the Garage tab strip vertically (GEAR-01, GEAR-02).
- Garage Inventory low information density (GEAR-03, GEAR-04) — −85 net lines, dense `DividedRowList`.
- Sync/login on a separate route from Athlete profile (ACCT-01) — collapsed to 2-pane `/account`.
- Stale documentation: PRODUCT.md with `#547597` palette + dark-mode parity (DOC-01); CLAUDE.md font drift (DOC-02).

**Issues Deferred:**
- Dark mode — explicit out-of-scope; tracked for a future milestone.
- Palette migration to `#547597` — rejected outright; PRODUCT.md was rewritten to match shipped orange instead.
- Targeted performance work — beyond what naturally fell out of cleanup, no perf phase.

**Tech Debt Created:** None tracked. Phase 5 closeout in `STATE.md` reports clean tech debt at milestone end.
