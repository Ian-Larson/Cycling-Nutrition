# Version 1.3 Plan: Engine Fix, Guide Overhaul, Form Polish, UX Improvements

## Status: Implemented

## Summary of Changes

### Phase 1: Fix Recommendation Engine (Solids-First)
- Rewrote `recommendSolids()` to allocate solids first at preferred rate, not gap-fill
- Added `MIN_DURATION_FOR_SOLIDS_MINUTES = 30` constant
- Rewired calculator orchestrator to remove `carbGap` flow
- Concentrated drink mix into fewer bottles; bottles with < 3g mix marked `isWaterOnly`
- Added `isWaterOnly` field to `BottleAllocation` type
- Water-only bottles display "Water only" in results

### Phase 2: Consumption Guide Overhaul
- Changed sip interval from 15 → 30 minutes
- Added `formatTime()` helper ("0:30", "1:00" format)
- Added `snapToFraction()` for bottle fraction text ("~1/2", "~1/3", etc.)
- Drink actions now show "Drink ~1/2 of 550ml Small" instead of raw carb grams
- Water-only bottles show "(water)" suffix in guide
- Time display uses `formatTime()` in fuel-result

### Phase 3: Ride Form Layout Fix
- Moved section titles (Duration, Carb Target) above preset buttons
- Removed label/displayValue props from Slider (now shown in separate header)

### Phase 4: Drink Mix Selector → Toggle-Based
- Replaced Select dropdown with toggle rows mirroring solid-fuel-selector
- Radio behavior: one active at a time, clicking active toggle is no-op

### Phase 5: UX Polish
- **Delete confirmation**: Inline "Confirm?" button (danger variant) with 3s auto-reset on bottle-card, product-card, history page
- **Toast notification**: New `Toast` component replacing `alert()` for plan save feedback
- Added `animate-fade-in` CSS animation
