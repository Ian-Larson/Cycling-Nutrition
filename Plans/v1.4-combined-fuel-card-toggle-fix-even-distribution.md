# Version 1.4 Implementation Plan

## Context

User feedback identified 4 areas for improvement: the Drink Mix and Solid Fuel cards should be combined, toggles have a bug and inconsistent styling, the consumption guide distributes carbs unevenly across hours, and there's no way to export current state for debugging.

---

## Phase 1: Fix Drink Mix Toggle Bug + Consistent Toggle Verbiage

**Files:**
- `src/components/planner/drink-mix-selector.tsx`
- `src/components/planner/solid-fuel-selector.tsx`
- `src/components/bottles/bottle-card.tsx`

### Toggle Bug Fix
The drink mix toggle only fired `onChange` when `!isSelected`, making it impossible to untoggle. Fixed by:
- Changed `onChange` prop type from `(id: string) => void` to `(id: string | null) => void`
- Changed handler to: `onChange(isSelected ? null : mix.id)`
- Removed the fallback `const activeId = selectedId || drinkMixes[0].id` — let `null` mean "none selected" visually

### Toggle Verbiage & Alignment
Standardized all toggles to **"On" / "Off"** with width `w-10`.

---

## Phase 2: Combine Drink Mix + Solid Fuel into "Fuel Options" Card

**Files:**
- `src/components/planner/fuel-options-card.tsx` (new)
- `src/pages/planner.tsx`

Created `FuelOptionsCard` that wraps both selectors in a single Card with section sub-headings ("Drink Mix" and "Solids") separated by a divider. The card is always visible (not gated behind `canCalculate`).

---

## Phase 3: Fix Uneven Carb Distribution in Consumption Guide

**Files:**
- `src/lib/calculator/timing.ts`

Rewrote `generateConsumptionGuide()` to use hour-bucket distribution:
1. Divide ride into hour buckets
2. Distribute solids round-robin across hours (respecting PREFERRED/MAX per-hour limits)
3. Distribute sips proportionally across hours
4. Within each hour, space events evenly and interleave sips/solids
5. Preserve refuel stop logic

---

## Phase 4: Add Debug Copy Button

**Files:**
- `src/components/planner/debug-copy-button.tsx` (new)
- `src/pages/planner.tsx`

Added a subtle "Copy Debug Info" ghost button below "Save to History" that copies all current state to clipboard as formatted text including ride settings, selections, bottles, solids, summary, and consumption guide.
