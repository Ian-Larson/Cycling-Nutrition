# Version 1.2 Plan: Recommendation Engine, Product Editing, Inventory Page, Toggle Fix

## Context

User feedback from v1.1 identified four changes: (1) the solid fuel selector should be a recommendation engine that auto-balances liquid and solid fuel rather than requiring manual quantity input, (2) products need edit support, (3) Bottles and Products pages should merge into a single "Inventory" page, and (4) the toggle switch has a layout-shift bug.

## Phase 4: Smart Solid Fuel Recommendation Engine

**Why**: Instead of the user manually picking how many gels to bring, the system auto-recommends the optimal solid+liquid balance based on the ride, weather, and available products.

### Design

**New flow**:
1. User toggles which solid products are "available" (like bottles) instead of +/- steppers
2. Calculator determines how many carbs bottles can safely carry (concentration limit)
3. Carb gap = total needed - max liquid carbs
4. System recommends solids to fill the gap: ~1/hour preferred, max 2/hour
5. Drink mix concentration is reduced (less powder per bottle) when solids supplement carbs

### 4A. New constants
**File**: `src/lib/calculator/constants.ts`
- `MAX_SOLIDS_PER_HOUR = 2`
- `PREFERRED_SOLIDS_PER_HOUR = 1`

### 4B. Solid recommendation algorithm
**New file**: `src/lib/calculator/solids.ts`
- `recommendSolids(availableSolids, carbGapGrams, durationMinutes)` -> `SolidRecommendation[]`
- Phase 1: allocate at preferred rate (~1/hr), round-robin across products sorted by carbs desc
- Phase 2: if gap remains, increase up to max rate (2/hr)

### 4C. Refactor bottles.ts
- `selectBottlesForHydration(available, ride)` -> `Bottle[]`
- `calculateMaxLiquidCarbs(bottles, refuelStops)` -> number
- `allocateMixToBottles(bottles, carbsPerFill, drinkMix)` -> `BottleAllocation[]`

### 4D. Refactor calculator flow
**File**: `src/lib/calculator/index.ts`
- `CalculatorInput` now takes `availableSolids: Product[]` instead of manual quantities
- New flow: select bottles -> calc max liquid carbs -> carb gap -> recommend solids -> allocate reduced drink mix

### 4E. Toggle-based solid selector
**File**: `src/components/planner/solid-fuel-selector.tsx` — rewritten
- Toggle interface instead of +/- steppers
- Props: `{ solidProducts, selectedIds, onChange }`

### 4F-4G. Planner + FuelResult updates
- Planner passes `availableSolids` to calculator
- FuelResult shows "Recommended Solids" card with product name, quantity, carbs, timing
